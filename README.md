Random Joke Generator

A simple and interactive web application that displays random jokes and lets users reveal the punchline with a fun flip-card animation. The project features a collection of humorous Malayalam and English wordplay jokes stored locally, making it lightweight and fast.

Features
🎲 Generate a random joke with a single click
🙈 Reveal the punchline using a flip-card animation
😂 Includes a collection of Malayalam and English jokes
📱 Fully responsive design for desktop and mobile
⚡ Built using HTML, CSS, and JavaScript
Technologies Used
HTML5
CSS3
JavaScript
